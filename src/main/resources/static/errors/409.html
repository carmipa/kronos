409 Código HTTP 409 — a requisição conflita com o estado atual do recurso

Conflito de estado Onde houve o conflito

A operação colide com o estado atual do recurso — por exemplo, uma legenda que já está em processamento, um lote já remuxado ou um arquivo com o mesmo nome no cache local.

Recarregue o painel para ver o estado mais recente antes de repetir a ação. Se o conflito for de cache, use a Correção de Cache (2.3). Sugestão de ação para resolver ou contornar o problema
