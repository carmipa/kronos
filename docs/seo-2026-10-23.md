## O que mudou

- **`robots.txt` e `sitemap.xml`** respondidos pela própria vitrine (`GuardaVitrine`), montados de
  uma fonte única, `vitrine/application/IndexacaoVitrine`: a lista de páginas públicas (`/`), o
  endereço canônico e a lista do que os buscadores não devem buscar — `/api` e os 7 pedaços de tela,
  cada um pelo arquivo exato (a pasta deles tem o CSS e o JS que o buscador usa para desenhar a
  página). As páginas de erro ficam abertas de propósito: levam `noindex`, e caminho fechado no
  `robots.txt` nunca é buscado. Coletores de IA e robôs de SEO comerciais ficam fechados.
- **`/index.html` → 301 para `/`**, um endereço só para o mesmo documento.
- **`<head>`**: `<link rel="canonical">` e `og:url` em `https://kronos.carminati.dev.br/`, Open Graph
  completo e `og:image` 1200×630 (`img/og-kronos.png`, recorte do painel inicial).
- **Imagens**: logotipo com `width`/`height` e `alt=""` (o nome está escrito ao lado); pôster da
  obra com dimensões. Ícone do título "Documentação" com `aria-hidden` e `translate="no"`.

O endereço canônico é constante, nunca o cabeçalho `Host` da requisição. Como o `index.html` é
estático, o mesmo endereço aparece no `<head>`, e o teste confere que os dois batem.

**Observação (não reprova nenhum item).** No DOM renderizado, a dica de ajuda de cada título é
montada **dentro** do próprio título: o texto completo do `<h1>` passa a ser "Painel Inicial" + o
texto da dica (oculto por `visibility:hidden`) + o botão "Ajuda sobre Painel Inicial". O mesmo
acontece em 75 títulos da página. O HTML servido não tem isso, porque a dica é montada pelo script.
O peso que o buscador dá ao texto oculto dentro de um título é **inferência, não medição**. Se for
mudar, a mudança é no componente de dica, não nesta página.

foi conferida nesta revisão.

### O que a revisão das telas poderia ter mudado, e não mudou

- **Texto do título da página.** O ícone do `<h1>` ("Painel Inicial" e o título de cada tela) é
  desenhado por CSS (`::before` com texto alternativo vazio), não por um elemento com o nome do
  glifo: o texto do `<h1>` continua sendo só o título, para o buscador e para o leitor de tela.
  Os demais títulos levam o glifo como elemento `aria-hidden`; o nome do glifo entra no texto do
  documento renderizado. O peso disso para o buscador é inferência, não medição.
- **Dica dentro do título.** Continua montada pelo script (observação de 23/10); o HTML servido não a
  tem.
- **Páginas de erro.** Geradas de novo (v1.3.0): seguem com `noindex, nofollow`, fora do `Disallow`.
